# Путешествие по Поднебесью

Браузерная игра по миру «Княжича»; текущая игровая версия **v0.3.5**.

## Запуск
Нужен статический HTTP-сервер: ES-модули браузера не загружаются напрямую из `file://`.

```bash
python -m http.server 8000
```

Открой `http://localhost:8000/` для игры или `http://localhost:8000/vk-preview.html` для проверки разных размеров VK Mini Apps.

## Разделение кода
- `src/data.js` — игровой каталог, граф карты, сведения для путеводителя.
- `src/engine.js`, `src/rng.js`, `src/graph.js`, `src/catalog.js` — правила и расчёты.
- `src/bots.js`, `src/bot-assignment.js` — поведение компьютерных соперников.
- `src/rewards.js`, `src/guide.js`, `src/route-list.js` — прогноз наград и справочные механики.
- `src/main.js` — интерфейс и обработчики.
- `src/assets*.js` — исходные изображения в автономных WebP-данных.
- `styles/base.css` — исходный стиль, `styles/vk-responsive.css` — адаптивная надстройка.

`main` сохраняет неизменённый монолит v0.3.5. Работы ведутся только в ветке `feature/vk-responsive-modules`. VK Bridge, регистрация и публикация мини-приложения пока не выполняются.

## Проверки
```bash
npm test
```
Проверки исходников не заменяют ручной игровой прогон в мобильном и настольном окне. Подробнее см. `VK-ADAPTATION.md`.
