# Путешествие по Поднебесью · v0.3.5 — модульная сборка
Тестовая веб-версия под размеры VK Mini Apps; **без публикации во ВКонтакте**.
Код разложен по модулям, 88 исходных WebP-файлов вынесены в `assets/`; игровой баланс и данные исходной версии не менялись.
Ветка: `feature/vk-responsive-modules`. Ветка `main` хранит оригинальную автономную версию v0.3.5.
Проверять можно прямо в браузере через статический веб-хостинг (без Python и без установки зависимостей).
`index.html` — сама игра; `vk-preview.html` — стенд размеров; переключение размера iframe сохраняет текущую игру.
Структура: `src/data/` — данные, `src/core/` — движок, `src/gameplay/` — боты, `src/app/` — интерфейс, `styles/` — стили, `assets/` — изображения.
Для разработчиков: `node tests/logic-smoke.mjs` проверяет игровую модель, запуск и 15-дневную симуляцию.
Не публиковать в ВК до ручной проверки игровых сценариев и жестов карты.
