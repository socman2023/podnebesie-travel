# Подготовка игры к VK Mini Apps (без публикации)
Рабочая ветка: `feature/vk-responsive-modules`. Исходная игра v0.3.5 в `main` не изменяется.

## Текущее состояние
- `vk-preview.html` — локальный стенд для проверки ширины и высоты области приложения (360, 390, 768, 900 и 1200 px). Переключение размера не перезагружает iframe.
- `styles/vk-responsive.css` — подготовленные дополнительные стили. Пока **не подключены** к существующему `index.html`, то есть в игровом окне стенда отображается неизменённая v0.3.5.
- Извлечение изображений, данных, движка и представления из исходного монолитного файла ещё необходимо завершить. Не удалять оригинал, пока новая точка входа не пройдет функциональные тесты.

## Целевая структура
```
index.html
styles/base.css
styles/vk-responsive.css
src/assets.js
src/data.js
src/core.js
src/ui.js
vk-preview.html
```

## Обязательная проверка перед переключением
- Старт, выбор героя/ботов, запуск игры.
- Перемещения, прогноз очков, сортировка вариантов, пагинация.
- События, решения, начисление очков, ходы ботов, окончание партии.
- Карта: жесты, масштаб, выбор узлов.
- Справочник, окна событий, доступность кнопок на узких экранах.
- Нет горизонтального скролла страницы, модальные окна прокручиваются.
- Нет JavaScript-ошибок и отсутствующих картинок.

Пока нельзя считать модульную версию готовой и отправлять игру во ВКонтакте.
