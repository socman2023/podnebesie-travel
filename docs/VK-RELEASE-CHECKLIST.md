# VK Mini Apps — подготовка к размещению

## Статус
- Браузерная игра v0.3.5 опубликована через GitHub Pages: https://socman2023.github.io/podnebesie-travel/
- Основная ветка `main` — исходная автономная версия.
- Ветка `feature/vk-responsive-modules` — модульная адаптивная версия, используемая как основа VK Mini Apps.
- Ветка `gh-pages` — действующая браузерная версия; не изменять её при подготовке VK без тестирования.
- Публикация во ВКонтакте и модерация **ещё не проводились**.

## Карточка игры (предложение на согласование)
**Название:** Путешествие по Поднебесью

**Краткое описание:** Отправляйся в путешествие по миру «Княжича»! Исследуй города, выбирай маршруты, получай награды и соревнуйся с компьютерными соперниками.

**Полное описание:** «Путешествие по Поднебесью» — настольная приключенческая игра по миру литературного цикла «Княжич». Выбери одного из восьми учеников Академии Светозара, бросай кубик, выбирай маршруты по карте, участвуй в событиях и набирай очки. Открывай города и государства, собирай грамоты, знакомься с Поднебесьем во встроенном путеводителе. Компьютерные путешественники будут соперничать с тобой за победу. Игра рассчитана на одного участника и не требует отдельной регистрации.

**Категория:** Игры; если доступна, подкатегория настольные.

**Палитра:** #12263A, #156E9A, #F7F5EE, #D8B45E.

## Основные сценарии для модерации
1. Запуск -> приветствие -> выбор героя.
2. Выбор параметров партии и компьютерных соперников -> начало партии.
3. Бросок кубика -> просмотр вариантов маршрута -> выбор и подтверждение хода.
4. Игровое событие -> выбор действия -> начисление очков.
5. Карта, справочник и награды; завершение партии -> таблица результатов -> новая партия.

## Технические задачи ДО модерации
1. Создать карточку VK Mini Apps через кабинет разработчика, получить app ID.
2. Сверить актуальные требования к графическим изображениям **в реальных полях кабинета** (иконка, обложка, скриншоты для мобильных и desktop). Подготовленные размеры — макеты, не гарантия окончательных технических требований.
3. Выбрать адреса запуска для мобильного клиента и desktop. Запуск по HTTPS.
4. Подключить VK Bridge и отправку `VKWebAppInit` при запуске внутри VK, не затронув прямой запуск сайта.
5. Проверить внутри VK: страницу приветствия, выбор героя, карту/жесты, ходы, события, ботов, справочник, модальные окна, завершение партии и переходы назад.
6. Проверить `.gitignore`, отсутствие секретов, корректную загрузку изображений и отсутствие JS-ошибок.
7. Заполнить контакты и юридические поля на основе реальной информации владельца, без выдуманных адресов.
8. Выбрать положение элементов управления: по возможности над игровым окном, чтобы не перекрывать интерактивную карту.
9. Отправка на модерацию — **только после одобрения пользователем**, не автоматически.

## Изображения
Макеты и скриншоты подготовлены отдельным комплектом для проверки и согласования; в основную игру не встроены.
